## Folitecta 0.0.3 — comment styles, measurements and form design

A free PDF editor written entirely in Rust with a Dioxus desktop interface.

**Highlights**

- Every comment can be restyled from the properties pane: colour, fill, opacity, thickness,
  dashes, line endings, text size, colour and alignment. Each tool remembers its default style,
  and styles can be copied from one comment to another.
- Comment appearances are generated by Folitecta, so moved, resized and restyled comments look
  the same in every PDF viewer.
- New comment tools: polygon, polyline, cloud, callout, free highlight, eraser for pencil
  strokes, insert-text and replace-text marks, file attachments.
- Measurements: distance, perimeter and area with a calibrated scale, labels on the page and CSV
  export.
- Form design: draw text, check box, radio button, combo box, list box, button and signature
  fields, then edit their properties in the properties pane. Fields can be filled directly on
  the page, and their values imported or exported as XFDF, FDF, CSV or text.

**Binaries**

| Platform | File |
|---|---|
| Windows x64 | `folitecta-0.0.3-windows-x64.zip` |

right-click → Open on first launch.

The status of every command is listed in `docs/FEATURES.md`; known limitations are in
`docs/ARCHITECTURE.md`.
